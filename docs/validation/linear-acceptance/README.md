## Explicit acceptance refinements

The original ticket criteria are retained in [criteria.json](criteria.json). The implementation accepts these measured refinements rather than claiming the original stronger wording:

- **COURSE-240/249:** private inline Lexical UI is deferred until a rich-text terminal is used. Payload v3 native peers and scoped native Lexical CSS may prepare on activation because native `buildFormState(renderAllFields)` must evaluate unmounted conditions, permissions and custom fields. This explicit policy preserves one native Form. Before activation, visitor resources exclude the native editor. See ADR 0008 and feature receipts.
- **COURSE-244:** heavy media picker UI and library requests are lazy. Lightweight consumer strategy/adapter registration can load on activation; it is not the picker implementation. Image/video tests establish reference handling, not video playback.
- **COURSE-246:** PostgreSQL is the authoritative transactional, atomic one-winner concurrency matrix. Mongo is a supported single-writer development fallback; its passing tests are not evidence of atomic multiwriter behavior.
- **COURSE-253:** the public test-kit entrypoint is in the tested immutable archive. Publication is intentionally held by the owner's no-push instruction.

Existing hook-dependency migration warnings remain visible. Real browser composition and touch tests are browser-emulated, not hardware IME/touch certification. Cache and latency receipts describe these measured fixtures and machines, not universal performance promises.

## Audit corrections

The final audit found and fixed stale native field selection after path changes; multiline DOM ownership loss after Enter; ownership reclassification during structural reindex; failed-file retry incorrectly searching rather than uploading; populated polymorphic media IDs colliding across collections; native date controls missing accessible labels; and a cache gate reading the wrong Turbo run summary. Tests now exercise these boundaries in the actual native form and independent package consumer.

Rich text preserves unknown/custom/upload islands and native link metadata. Disabled/collapsed link commands do not mutate content. Opaque rendered projections fall back to native settings without overwriting hidden source text. Native validation, permissions, current revision and explicit reviewed publication remain authoritative throughout.
