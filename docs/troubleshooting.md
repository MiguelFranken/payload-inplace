# Troubleshooting

Start with the exact peer matrix and one collection/root. Follow [getting started](getting-started.md) in order; each step has a check.

| Symptom                                                | Check and fix                                                                                                                                                                                                                                              |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No Edit page launcher                                  | Authenticate a CMS editor, verify native update access plus `canEdit`, enable tools and ensure the public route renders `EditorLauncher`. Reader accounts intentionally receive none.                                                                      |
| Entering edit mode fails with 403                      | Check current session, signed scope, native permissions and the exact configured origin/alias. Reauthorize; do not disable CSRF or accept arbitrary Host headers.                                                                                          |
| Loopback/TLS internal server error behind Portless     | Preserve `request.url` authority in the rewrite, change only pathname, and enable `skipProxyUrlNormalize`. Keep matching on `request.nextUrl.pathname`. No hardcoded backend port is needed.                                                               |
| The URL changes or header/footer disappear             | `resolvePagePath` must return the website pathname; the internal active entry and public entry must share the normal layout and `EditorPageTransition`.                                                                                                    |
| Only a whole block is selectable                       | Add explicit leaf bindings to headings/body/media. Bind row IDs with `getArrayItemPath`; text matching does not auto-map your renderer.                                                                                                                    |
| Plain text opens native settings                       | Confirm the field is native text/textarea, actually rendered, writable and allowed by the inline profile. Links/buttons, opaque transformed text, custom Field overrides and `edit: 'panel'` intentionally stay native.                                    |
| An RTE opens a panel                                   | Bind the native Lexical leaf; include it in any `inlineEdit` whitelist. Check supported features/custom overrides and renderer restrictions in the [rich-text guide](guides/rich-text.md).                                                                 |
| Native answer is empty although the website shows text | Check which field the renderer actually uses. A plain fallback and rich alternative are distinct paths. Bind the visible source; do not populate an empty sibling and overwrite the existing answer. Use 0.0.9+ for selected native field retention/focus. |
| `Cannot use 'in' operator … 'hidden' … undefined`      | Keep Payload/UI/Next packages on the exact supported version, regenerate both maps and restart after schema edits. The v3 bridge synchronizes native caches by schema identity. Do not pass a stale client schema or the unrelated admin map.              |
| Fields have huge gutters or sideways scrolling         | Use `frontendConfig` and the dedicated map/native bridge. Do not load the admin RootLayout CSS. Native panel padding and gutter share `--pve-panel-padding`; remove host styles targeting all inputs/groups.                                               |
| Image opens the full native upload control             | Register the [media strategy](guides/media.md) in the frontend map; omit `edit: 'panel'` on single-reference media bindings. Has-many/custom/compound fields remain native.                                                                                |
| Hovering Add section shows no page preview             | Provide valid `catalogue[slug].example`, a `preview` using `useEditorPreviewData`, and a renderer supporting the example block. A server-only slot needs an explicit example/empty state. [Section guide](guides/sections.md).                             |
| Previewed copy is not inserted                         | Intentional: catalogue examples are presentation-only. Define native `defaultValue` or opt into saved section patterns.                                                                                                                                    |
| Optional empty field cannot be selected                | Nothing rendered means nothing to click. Keep a parent/row binding or use all section fields. Do not invent persisted placeholder content on focus.                                                                                                        |
| Changes appear instantly but save fails                | Optimistic display is not a save acknowledgment. Keep the working copy, correct native validation, or explicitly retry/reconcile. Never add an independent PATCH loop.                                                                                     |
| Published content seems unchanged                      | Draft save and publication differ. Review the saved draft and publish that reviewed revision; verify your host's published cache revalidation.                                                                                                             |
| Review/publish is unavailable                          | Wait for current native save, resolve validation/conflict/lease state, and check native publish authority. A changed revision invalidates an older review.                                                                                                 |
| Duplicate context or Lexical errors                    | Check duplicate package/runtime installations and the exact native/Lexical versions. Use public entrypoints, regenerate maps and rebuild.                                                                                                                  |

Enable `diagnostics: true` in **development** for bounded path/reason codes on explicit selections. It prints no field values and does not grant access. For a reproducible report include package/peer versions, root/schema shape, binding code, expected/actual behavior and a synthetic fixture. Never include tokens, cookies or private draft data. [Report an issue](https://github.com/MiguelFranken/payload-inplace/issues) · [Test your integration](testing-and-extensions.md).
