# Selection controls and renderer presentation

Version 0.0.8 joins the selection caption to the outline's leading edge, with a square adjoining corner. Settings and optional reset actions live in that caption; hover targets never receive another selection's actions. The caption clamps to the remaining viewport width. Editing controls use neutral active/hover states; review remains the primary accent action. Canvas insertion uses a neutral outlined button, white separation halo without a decorative boundary line.

A reset is offered only for a schema-resolved, initialized, writable native field. Required, hidden, read-only, conditional, custom, has-many and compound values stay in native settings. Supported optional text values clear to an empty string; nullable scalar/reference/rich values clear to null. A row binding removes the array item, rather than clearing its children, only above the field's minimum. Both actions ask for confirmation. Removal re-resolves the current row identity and participates in structural undo. Undo from an empty list restores Payload's `disableFormData` row-count contract.

The rich-text regression came from shallow-cloning the bound outer wrapper and putting all Lexical blocks directly inside it. That discarded inner prose classes, grid-column placement and spacing rules. The inline adapter now clones the renderer's single-child presentation wrapper chain and mounts Lexical at its original rich-content container. Semantic classes remain responsive CSS. Existing per-node classes are retained by Lexical identity; newly inserted nodes use only common semantic classes. Lexical retains its required editable whitespace handling so typed spaces cannot be lost; block layout, wrapping and computed typography remain consumer-owned. Unknown structured nodes still retain their lossless native JSON contract and native settings fallback.

Local domain/component validation: 247 tests across 81 files, types and lint. Focused production/Postgres browser coverage compares headings, paragraphs, emphasis, links, lists and quotes before/during editing at 1280px and 320px, plus native reset/row deletion/undo and slow-save structured-rich-text behavior. Consumer acceptance covers the actual Workshops coupon and offset-news renderers. Final release/deployment results are recorded in `workshops-release.json`.
