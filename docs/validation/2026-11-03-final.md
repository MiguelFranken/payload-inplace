## Release and rollout boundary

This is an experimental alpha with exact Payload/UI/Postgres 3.91.0, Next 16.4.2, React 19.2.6 and Postgres 17.11 evidence. The clean app installs public peers anonymously. Mongo remains a development single-writer fallback. Globals, localized editing, cross-origin editing and embedded Lexical-block editing are unsupported; peer ranges are not broadened without evidence.

The public source and immutable GitHub prerelease artifact are distinct from npm publication and application deployment. The manual release workflow defaults to preparation only, verifies the exact successful main artifact plus committed matching Workshops receipt, and isolates optional npm OIDC permission in its protected publish job. No npm account/trusted-publisher setup or stable npm publication is claimed here.

Workshops authoring remains off by default. Runtime disable retains revision columns and native guards; preserve content and migration history. The previously tested alpha.2 archive is retained for a compatible UI rollback, otherwise keep current guards and use native CMS with authoring disabled. No down migration, customer communication or historical business replay belongs to a UI rollback. Actual production CDN/cookie/prefetch/service-worker validation and application deployment remain a separate delivery decision.
