# Package icon

The mark combines a webpage frame, a selected content block and a pointer. Cobalt connects it to the editor's existing accent; the independent symbol does not reuse Payload's logo.

- Asset: [icon.png](icon.png), 1254 × 1254 PNG with transparency.
- Generated with the built-in `image_gen` tool, then refined once. The final original PNG is included unchanged.
- Use the transparent image on light or dark surfaces. The README displays it at 96 × 96.

The icon predates the package rename; its original generation prompts are retained verbatim below.

## Initial prompt

Use case: logo-brand.
Asset type: original square package icon for Payload Visual Editor, an independent open-source frontend live-editing plugin.
Primary request: a distinctive, restrained geometric software mark expressing editing a block directly on a webpage. A bold white open webpage/frame shape with one simple inset content block and a small integrated pointer/editing corner, designed as one coherent symbol, not a collage of stock icons.
Style: exceptionally crisp vector-like flat geometry, strong negative space, optically balanced, friendly rounded corners, legible at 32px. Premium developer-tool identity.
Palette: the editor's existing cobalt blue (#3847F4) as a solid rounded-square tile, white main symbol, at most one pale blue detail. Truly transparent outside the tile. Centered square composition, generous safe margin.
No text, letters, initials, gradients, shadows, 3D, texture, device mockup, badges, watermarks, or copied Payload/other company logo. Return one finished icon only.

## Refinement prompt

Refine this package icon into an exceptionally clean flat vector-like mark for Payload Visual Editor. Keep the cobalt rounded square, white webpage frame and pointer idea. Simplify the inside to one white content line and one small blue-accent selection rectangle with the white pointer overlapping its lower right corner. Remove the browser's three dots and decorative selection corner marks to reduce clutter. Absolutely flat solid fills only: no gradients, grain, noise, texture, shadows, bevel, or translucent shading. Smooth geometric edges with even stroke weights and optically balanced spacing. Transparent background outside the cobalt tile; remove ALL stray colored pixels and marks outside the tile. Centered square icon, safe transparent margin, recognizable at 32px. No words or initials. Original independent open-source package identity; do not resemble Payload's official logo.
